# Loading Spinners personalizados

Gerador de animações de carregamento (loading spinners) em HTML, CSS e JavaScript. Ajuste **cor, tamanho e velocidade** em tempo real e **copie o CSS** do spinner que preferir com um clique.

## Spinners disponíveis

- Anel
- Anel duplo
- Pontos
- Barras
- Pulso
- Órbita
- Quadrado

## Funcionalidades

- Personalização ao vivo de **cor**, **tamanho** e **velocidade**
- Botão **Copiar CSS** em cada spinner
- Animações feitas com CSS puro (`@keyframes`)
- Layout responsivo com grid
- Tema escuro


## Tecnologias

- HTML5
- CSS3 (animações, variáveis CSS e grid)
- JavaScript

## O que aprendi

- Criar animações com `@keyframes`
- Usar variáveis CSS para personalizar estilos em tempo real
- Copiar texto para a área de transferência com JavaScript
- Montar layouts responsivos com grid
